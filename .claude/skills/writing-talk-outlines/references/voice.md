# Voice

How on-slide text and talk tracks sound in this project's decks. Filled from the user's
own corrections, one review at a time. Pairs beat rules: the editing pass checks the
outline against every pair and rule here, and a new deck must not repeat a correction
already recorded.

How to add to this file (done by the main agent right after a user review):

- A correction that rewrites a sentence becomes a pair under the slide role it belongs to:
  the original line, then the user's version, verbatim.
- A correction stated as a principle becomes one rule with one example, under Rules.
- Corrections about what belongs on a slide go to `building-decks/references/house-style.md`,
  Taste rules. Corrections about facts go to the outline. Neither goes here.
- Every few decks, merge duplicate rules and drop pairs that a rule now covers. Keep the
  rule list under fifteen.

## Defaults until there are pairs

Plain technical voice. Short declarative sentences. A number with its error rather than an
adjective. No em dashes, no exclamation marks, no "key", "crucial", "robust", "novel",
"insight", "takeaway", "landscape", "journey". No sentence that praises the work; the
number does that or nothing does. Sentence case throughout.
